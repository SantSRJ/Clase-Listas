    1.1¿Qué es una lista?5 min

    Definición

    Una lista es una colección ordenada y mutable de elementos. Se escribe entre corchetes [ ] con los elementos separados por coma, y puede guardar datos de distintos tipos, incluso repetidos.

    Ordenada

    Cada elemento tiene una posición fija (índice). [1, 2] != [2, 1].

    Mutable

    Se puede cambiar su contenido sin crear una lista nueva.

    Heterogénea

    Admite int, str, bool, otras listas… en la misma colección.

    Repetible

    Un mismo valor puede aparecer varias veces.

    Nota para el docente

    Remarcá la palabra mutable: es la idea que sostiene todo el módulo. Preguntá: “¿Un str es mutable?” y probá texto[0] = 'X' en vivo para contrastar.

    # Una lista se define con corchetes y elementos separados por coma
notas = [7, 9, 4, 9]          # Repetible: el 9 aparece dos veces
alumno = ["Ana", 20, True]    # Heterogénea: str, int y bool juntos
vacia = []                    # Lista vacía: ideal para acumular datos

print(notas)          # [7, 9, 4, 9]
print(len(notas))     # 4 -> cantidad de elementos
print(type(alumno))   # <class 'list'>

# Ordenada: el orden importa
print([1, 2] == [2, 1])   # False

# Mutable: cambiamos un elemento "en el lugar"
notas[2] = 6
print(notas)          # [7, 9, 6, 9]

# En cambio, un str NO es mutable
texto = "Hola"
texto[0] = "B"        # TypeError

    1.2Mutabilidad y referencias (aliasing)10 min

    Una variable es una etiqueta, no una caja

    Cuando escribís b = a, Python no copia la lista: pega una segunda etiqueta sobre el mismo objeto en memoria. A esto se lo llama aliasing. Cualquier cambio hecho a través de b se ve también desde a.

    Para trabajar de forma independiente hay que crear una copia: a[:], a.copy() o list(a).

    Probá el simulador: elegí cómo se crea b y después modificala.

    Alerta de error típico: copia superficial con listas anidadas

    .copy() y [:] hacen una copia superficial: copian la lista exterior, pero las sublistas siguen compartidas. Para listas de listas usá copy.deepcopy().

    import copy

matriz = [[1, 2], [3, 4]]
superficial = matriz.copy()
superficial[0][0] = 99
print(matriz)        # [[99, 2], [3, 4]]  <- ¡la original cambió!

matriz = [[1, 2], [3, 4]]
profunda = copy.deepcopy(matriz)
profunda[0][0] = 99
print(matriz)        # [[1, 2], [3, 4]]   <- intacta
    a = [1, 2, 3]
b = a              # NO copia: b es otro nombre para la MISMA lista
b.append(4)
print(a)           # [1, 2, 3, 4]  <- ¡a también cambió!
print(a is b)      # True: es el mismo objeto
print(id(a) == id(b))   # True: misma dirección en memoria

# Copias seguras: cada una crea una lista NUEVA
c = a[:]           # copia por slicing
d = a.copy()       # copia con método
e = list(a)        # copia con el constructor
c.append(99)
print(a)           # [1, 2, 3, 4]       <- a no se entera
print(c)           # [1, 2, 3, 4, 99]
print(a is d, a == d)   # False True -> distinto objeto, mismo contenido
    # El aliasing también ocurre al pasar listas a funciones
def agregar_bonus(notas):
    notas.append(10)          # modifica la lista ORIGINAL
    return notas

mis_notas = [7, 8]
agregar_bonus(mis_notas)
print(mis_notas)              # [7, 8, 10] <- efecto colateral

# Versión segura: trabajar sobre una copia
def agregar_bonus_seguro(notas):
    copia = notas.copy()
    copia.append(10)
    return copia

originales = [7, 8]
nuevas = agregar_bonus_seguro(originales)
print(originales, nuevas)     # [7, 8] [7, 8, 10]

    1.3Índices, slicing y prevención de IndexError10 min

    Guía visual de índices

    Ana0-4
    Luis1-3
    Sofía2-2
    Carlos3-1

    Los índices positivos cuentan desde el inicio empezando en 0. Los negativos cuentan desde el final: -1 es siempre el último. El último índice positivo válido es len(lista) - 1.

    Slicing: lista[inicio:fin:paso]

    inicio

    Desde dónde (incluido). Si se omite: el principio.

    fin

    Hasta dónde (no incluido). Si se omite: el final.

    paso

    De a cuánto avanzar. Negativo: recorre al revés.

    numeros[::] 
    nombres = ["Ana", "Luis", "Sofía", "Carlos"]
print(nombres[0])     # Ana     -> primer elemento
print(nombres[-1])    # Carlos  -> último, sin calcular len - 1
print(nombres[-2])    # Sofía

numeros = [10, 20, 30, 40, 50, 60]
print(numeros[1:4])   # [20, 30, 40]  -> el fin NO se incluye
print(numeros[:2])    # [10, 20]      -> desde el inicio
print(numeros[3:])    # [40, 50, 60]  -> hasta el final
print(numeros[::2])   # [10, 30, 50]  -> de a 2
print(numeros[::-1])  # [60, 50, 40, 30, 20, 10] -> invertida (copia)
print(numeros[-3:])   # [40, 50, 60]  -> los últimos 3
print(numeros[4:100]) # [50, 60] -> el slicing NUNCA lanza IndexError
    nombres = ["Ana", "Luis", "Sofía", "Carlos"]
i = 10

# Opción 1: validar el rango ANTES de acceder
if 0 <= i < len(nombres):
    print(nombres[i])
else:
    print(f"El índice {i} no existe (válidos: 0 a {len(nombres) - 1})")

# Opción 2: el último válido SIEMPRE es len - 1 (o -1)
print(nombres[len(nombres) - 1])   # Carlos

# Sin validar...
print(nombres[i])                  # IndexError: list index out of range
    Alerta de error típico: el error del “uno de más” (off-by-one)

    Los tres casos que más se ven en clase:

    • lista[len(lista)] → IndexError: el último es len(lista) - 1.
    • for i in range(1, len(lista)) → se saltea el elemento de la posición 0.
    • for i in range(len(lista) + 1) → la última vuelta se pasa del rango.

    Regla práctica: range(len(lista)) genera exactamente los índices válidos.

    2.1Inserción y edición5 min

    append() vs insert()

    append() siempre agrega al final y es la operación más usada para acumular resultados en un bucle. insert(i, x) agrega en una posición concreta y desplaza a la derecha a todos los que estaban desde i.

    Para editar no hace falta ningún método: se asigna por índice, t[i] = nuevo_valor.

    Alerta de error típico: append de una lista

    t.append([4, 5]) agrega un solo elemento (una sublista), no dos números. Si querés sumar varios elementos, usá t.extend([4, 5]) o t += [4, 5].

    compras = ["pan", "leche"]
compras.append("huevos")        # agrega AL FINAL
print(compras)                  # ['pan', 'leche', 'huevos']

compras.insert(0, "café")       # inserta en la posición 0
print(compras)                  # ['café', 'pan', 'leche', 'huevos']

compras.insert(100, "sal")      # fuera de rango: NO falla, va al final
print(compras)                  # ['café', 'pan', 'leche', 'huevos', 'sal']

compras[1] = "pan integral"     # editar = asignar por índice
print(compras)

compras.append(["yerba", "azúcar"])   # ¡agrega UNA sola sublista!
print(compras[-1], len(compras))      # ['yerba', 'azúcar'] 6

compras.pop()                         # deshacemos
compras.extend(["yerba", "azúcar"])   # agrega los dos por separado
print(compras[-2:], len(compras))     # ['yerba', 'azúcar'] 7

    remove() vs pop() vs clear()

    remove(valor)

    Busca por valor y borra la primera coincidencia.

    pop(índice)

    clear()

    Eliminar elementos de la misma lista que estás recorriendo con for hace que se salteen elementos: al borrar, todo se corre una posición a la izquierda y el bucle avanza igual.

    [3, "dos", 1].sort() lanza TypeError: '<' not supported between instances of 'str' and 'int'. Python no sabe si "dos" va antes o después de 3. Ordená solo listas homogéneas.

print(notas)                 # [2, 4, 7, 9]

notas.sort(reverse=True)     # descendente
print(notas)                 # [9, 7, 4, 2]

notas.reverse()              # invierte el orden actual (no ordena)
print(notas)                 # [2, 4, 7, 9]

print(sorted(palabras, key=str.lower))   # ['ana', 'banana', 'Zoe'] -> orden "humano"

    2.4Operaciones in-place: por qué devuelven None7 min

    La regla de oro

    Los métodos que modifican la lista (append, insert, extend, remove, sort, reverse, clear) trabajan in-place: cambian el objeto existente y devuelven None. Es una decisión de diseño de Python para dejar claro que no se creó nada nuevo.

    ❌ Incorrectot = t.append(x)t = t.sort()
    ✅ Correctot.append(x)t.sort()

    Si necesitás un valor de vuelta, usá las versiones que crean: sorted(t), t + [x], t[::-1].

    Alerta de error típico: AttributeError: 'NoneType' object has no attribute…

    Si ves este mensaje, casi siempre hay una línea anterior del estilo t = t.algo(). El error aparece después, no donde está el problema: por eso cuesta encontrarlo. Buscá hacia arriba la última vez que asignaste t.

    t = [3, 1, 2]
resultado = t.append(4)
print(resultado)     # None -> append NO devuelve la lista
print(t)             # [3, 1, 2, 4] -> la modificó en el lugar

# El error clásico: reasignar el resultado
t = t.sort()
print(t)             # None -> ¡perdiste la lista!

t.append(5)          # AttributeError: 'NoneType' object has no attribute 'append'

    2.5Errores de concatenación5 min

    t + [x] vs t + x

    El operador + entre listas solo acepta otra lista y siempre crea una lista nueva (no modifica t). Para sumar un valor suelto, envolvelo en corchetes.

    ❌t + 4t + "hola"
    ✅t + [4]t + ["hola"]
    Alerta de error típico: += con un string

    t += "ok" no falla, pero agrega letra por letra: [..., 'o', 'k']. Es porque += funciona como extend() y recorre el string. Usá t.append("ok") o t += ["ok"].

    t = [1, 2, 3]
x = 4

nueva = t + [x]      # lista + lista = lista NUEVA
print(nueva)         # [1, 2, 3, 4]
print(t)             # [1, 2, 3] <- t no cambió

t += [x]             # equivale a t.extend([x]) -> modifica t
print(t)             # [1, 2, 3, 4]

t += "ok"            # trampa: agrega cada letra
print(t)             # [1, 2, 3, 4, 'o', 'k']

print([0] * 3)       # [0, 0, 0] -> repetición

t = t + x            # TypeError: can only concatenate list (not "int") to list

    3.2Patrón guardián (code guard)8 min

    Qué es un guardián

    Un guardián es una condición que se verifica al principio y corta el flujo si los datos no sirven: continue en un bucle, return en una función. El “camino feliz” queda sin anidar y el error nunca llega a ocurrir.

    Sin guardiánprimera = palabras[0]💥 IndexError con líneas vacías
    Con guardiánif len(palabras) == 0:    continue🛡️ salta la línea y sigue

    Forma más “pythónica”: if not palabras: (una lista vacía es falsa).

    Alerta de error típico: split(" ") no es lo mismo que split()

    " ".split() devuelve [], pero " ".split(" ") devuelve ['', '', '', '']: ¡una lista de 4 strings vacíos! El guardián len(palabras) == 0 no la detecta. Para separar palabras usá split() sin argumentos.

    # En un archivo real, el guardián se ve así (no ejecutable acá)
with open("alumnos.txt", encoding="utf-8") as archivo:
    for linea in archivo:
        datos = linea.strip().split(",")
        if len(datos) < 2:          # guardián: línea vacía o incompleta
            continue
        nombre, nota = datos[0], int(datos[1])
        print(nombre, nota)
    # Simulamos las líneas de un archivo de texto

for num, linea in enumerate(lineas, start=1):

    A3
    Recorrido con paso negativo
     Avanzado
    
  
    (1) Imprimí la lista de atrás hacia adelante con range() y paso -1, mostrando índice y valor. (2) Eliminá los duplicados en la misma lista usando solo pop(índice) (sin remove() ni listas auxiliares).
    
  
     Tu solución
    
  
    
  
     Ver pista
    range(len(t) - 1, -1, -1) va desde el último índice hasta 0. El fin es -1 porque no se incluye. Recorrer al revés permite hacer pop(i) sin desordenar los índices que faltan visitar.
    
  
     Ver solución explicada
    1. range(inicio, fin, paso) con inicio = len(t) - 1, fin = -1 y paso = -1.
    2. Para cada posición i, el elemento es repetido si ya aparece antes: t[i] in t[:i].
    3. Si es repetido, t.pop(i). Como vamos de atrás para adelante, los índices menores no se corren: ¡por eso funciona!
    4. Probalo recorriendo hacia adelante y vas a ver el mismo problema que en la alerta “borrar mientras recorrés”.
    t = [3, 1, 3, 2, 1, 5, 2]

# 1. Recorrido inverso con índices
for i in range(len(t) - 1, -1, -1):
    print(f"t[{i}] = {t[i]}")

# 2. Sin duplicados, in-place, solo con pop()
for i in range(len(t) - 1, -1, -1):
    if t[i] in t[:i]:          # ¿ya apareció antes?
        t.pop(i)
print(t)                       # [3, 1, 2, 5]

    Racha más larga de crecimiento
     Nivel Dios
    
  
    Una empresa registró sus ventas diarias. Encontrá la racha más larga de días consecutivos en que las ventas crecieron respecto del día anterior. Mostrá la cantidad de días, los índices de inicio y fin, y los valores de esa racha. Un solo recorrido, sin funciones de librería.
    Salida esperada
    Días de la racha: 5
Desde el índice 3 hasta el 7
Valores: [140, 145, 160, 175, 190]
    
  
     Tu solución
    
  
    
  
     Ver pista
    Llevá dos “memorias”: la racha actual (dónde empezó y cuánto mide) y la mejor vista hasta ahora. Compará cada día con el anterior: ventas[i] > ventas[i - 1].
    
  
     Ver solución explicada
    1. Guardián: con una lista vacía no hay racha.
    2. Una racha mínima mide 1 día: arrancá con inicio_actual = 0, largo_actual = 1 y la mejor igual.
    3. Recorré desde i = 1 (cada día se compara con el anterior). Si creció, largo_actual += 1; si no, la racha se corta y empieza otra en i.
    4. Después de actualizar, si largo_actual supera al mejor, guardá inicio y largo.
    5. El fin es mejor_inicio + mejor_largo - 1 y los valores salen con slicing.

    print("Sin datos")

        if largo_actual > mejor_largo:      # ¿superó al récord?

            mejor_inicio = inicio_actual

    fin = mejor_inicio + mejor_largo - 1

    La lista tiene las ganancias (+) y pérdidas (−) diarias de un negocio. Encontrá el tramo de días consecutivos cuya suma sea la mayor posible. Mostrá la suma, los índices y los valores del tramo. Primero resolvelo “a fuerza bruta” y después intentá hacerlo en un solo recorrido.

    1. Para cada inicio i, sumá hacia adelante con j desde i hasta el final.
    2. Cada vez que suma supere al mejor, guardá la suma, i y j.
    3. Hace del orden de n² comparaciones: con 8 datos es instantáneo, con un millón no.

    1. actual = mejor suma de un tramo que termina en el día i.
    2. En cada día hay dos opciones: continuar el tramo (actual + v[i]) o empezar de nuevo (v[i]). Quedate con la mayor.
    3. Si empezás de nuevo, recordá dónde (ini_actual = i).
